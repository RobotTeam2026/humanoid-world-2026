# RobotTeams · HUMANOID WORLD 2026

Catálogo flipbook de 20 robots humanoides, con mejoras de experiencia de lectura y adaptación a pantallas pequeñas.

## Abrir en Visual Studio Code

1. Descomprime el ZIP.
2. Abre Visual Studio Code.
3. Selecciona **Archivo → Abrir carpeta** y elige `robotteams-humanoid-world-2026`.
4. Abre `index.html` para revisar el código.
5. Para probarlo en el navegador, puedes usar una extensión de servidor local, por ejemplo **Live Server**, y pulsar **Go Live**.

## Subir a GitHub

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` al repositorio, o usa Git desde Visual Studio Code.
3. Si quieres publicarlo con GitHub Pages, entra en **Settings → Pages** y selecciona la rama principal y la carpeta raíz (`/root`).

## Nota sobre las imágenes

El HTML contiene algunas referencias a rutas como `/media/robots/...`. Esas imágenes pueden no cargarse si los archivos correspondientes no se incluyen en el proyecto o no existen en el servidor. Este paquete conserva el HTML preparado; no incluye una carpeta de fotografías independiente porque no se encontró esa carpeta entre los archivos disponibles.
